# CharacterZero

Personal D&D 5e character sheet manager. Local-first, single-user.
Backend C++ serving both a JSON API and a static vanilla JS frontend.
Offline 5e data: classes, spells, feats, backgrounds, races, features.

## Features

- Character creation wizard (4 steps: class, stats, skills, spells)
- Full multiclass support (PHB p.164): spell slots, pact magic, third-casters
- ASI/feat slots per class (including Fighter/Rogue special progression)
- Spell management: multiclass slot pool, prepared/known tracking, explorable spell browser
- Token image upload (drag & drop, auto-crop, thumbnail)
- Offline D&D 5e Italian dataset: 429 spells, 13 classes, 103 subclasses, 42 feats, etc.
- REST JSON API for full CRUD

## Stack

- **Backend**: C++17, [cpp-httplib](https://github.com/yhirose/cpp-httplib) v0.18.1,
  [nlohmann/json](https://github.com/nlohmann/json) v3.11.3,
  [SQLiteCpp](https://github.com/SRombauts/SQLiteCpp) 3.3.2
- **Build**: CMake ≥ 3.20 (FetchContent, header-only deps)
- **Database**: SQLite (WAL mode, foreign keys, migrations)
- **Frontend**: Static HTML + vanilla JS (no bundlers/frameworks)
- **UI language**: Italian

## Build & Run

```bash
cmake -S . -B build
cmake --build build -j
./build/CharacterZero
# → http://127.0.0.1:8080
```

## Project Structure

```
CMakeLists.txt
src/
  main.cpp                 # entry point
  db/                      # SQLiteCpp wrapper + migrations
  domain/                  # Sheet entity, repository, schema
  server/                  # Router + JSON alias
web/
  index.html               # sheet list (home)
  new.html                 # character wizard
  sheet.html               # sheet view/edit
  spells.html              # spell browser
  css/                     # design system (dark premium)
  js/                      # vanilla JS widgets
  data/                    # 5e datasets (JSON)
tools/                     # Python offline pipeline
```

## API

| Method | Path | Description |
|--------|------|-------------|
| GET | `/api/health` | Health check |
| GET | `/api/schema` | Kind/subtype definitions |
| GET | `/api/sheets` | List all sheets |
| GET | `/api/sheets/:id` | Get sheet |
| POST | `/api/sheets` | Create sheet |
| PUT | `/api/sheets/:id` | Update sheet |
| DELETE | `/api/sheets/:id` | Delete sheet |

## Dataset

5e data is stored as JSON in `web/data/` and generated by an offline Python pipeline
that extracts spells, features, and class data from source manuals (OCR/pdftext).
See `tools/` for the extraction and correction toolchain.
